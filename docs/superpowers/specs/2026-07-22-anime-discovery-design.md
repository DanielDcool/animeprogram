# 动画发现首页设计

日期：2026-07-22
状态：用户授权自主设计并连续实现

## 1. 目标

在现有本地日语学习播放器上增加一个“先发现，再学习”的动画首页。用户打开应用即可看到当前季与上一季番剧、编辑推荐和搜索结果；进入详情后可查看简介、制作信息、官方播放资源，并回到本地媒体库扫描已经合法取得的视频。

首版完成后应满足：

1. `/` 是有封面、季番导航和推荐理由的动画发现首页。
2. 自动显示当前季度和上一季度；在 2026 年 7 月应对应“2026 夏 / 2026 春”。
3. 支持按日文、罗马字或英文标题搜索。
4. 动画详情包含简介、类型、评分、话数、制作公司和外部资源。
5. 外部资源只显示 AniList 标记的 `STREAMING` 与官方 `INFO` 链接；不聚合盗版播放页、磁力或不明下载文件。
6. 用户可从详情页进入本地媒体库，继续现有“扫描 → jimaku 字幕 → 学习播放”流程。
7. AniList 不可用时给出可恢复的错误界面，不影响本地媒体库和播放器。

## 2. 参考与取舍

嘟嘟噜早期产品强调追番进度、新番提醒、播放地址提示和社区；其作者也明确把全网追番管理放在资源提供之前。本项目借鉴其“发现—定位资源—继续观看”的信息架构，不复制社区、广告或未经授权的资源聚合。

方案比较：

- 静态季番 JSON：最快且离线可用，但名单、评分和资源链接会迅速过时。
- 浏览器直连 AniList：代码最少，但错误、限流和缓存散落到 React 组件，难以测试。
- **服务端 AniList 适配层（采用）**：Fastify 代理公开 GraphQL，集中做字段归一化、10 分钟内存缓存、成人内容过滤和错误映射；前端只依赖本项目 REST API。

AniList 公开数据不需要登录。应用只按页读取发现与搜索结果，不批量镜像数据；页面底部标注数据来源。

## 3. 页面与交互

### 顶部导航

品牌名使用「ことばアニメ」，导航为「見つける / ライブラリ / 単語帳 / 設定」。发现页成为 `/`，原媒体库移动到 `/library`；播放器仍是 `/play/:id`。

### 发现首页

- Hero 使用本季编辑推荐的 banner；包含日文标题、中文推荐理由、评分和“作品を見る”按钮。
- “今季まず見る3本”展示学习友好、口碑与题材互补的精选理由。
- 季番区用「7月新番 / 4月新番」标签切换，卡片展示封面、标题、评分、类型与状态。
- 顶部搜索框提交后显示搜索结果；清空后恢复季番首页。
- 卡片点击进入 `/anime/:id`。

2026 夏季优先推荐：

- `スーパーの裏でヤニ吸うふたり`：成人日常对话密度高，适合听力与口语素材。
- `攻殻機動隊 THE GHOST IN THE SHELL`：科幻题材与正式语域，适合挑战型观看。
- `無職転生Ⅲ`：制作与人气稳定，适合已有前作基础的用户。

2026 春季回看优先：`とんがり帽子のアトリエ`、`Re:ゼロ 4th season`、`氷の城壁`。这些理由作为本地编辑元数据按 AniList ID 合并，季番目录本身仍实时读取。

### 详情页

- banner + cover + 标题与元数据。
- 纯文本简介；服务端去除 AniList 描述里的 HTML。
- “公式で見る”列出 Crunchyroll、Netflix、YouTube 等 AniList `STREAMING` 链接。
- “公式サイト”仅使用 HTTPS `INFO` 链接。
- “ローカルで学ぶ”进入 `/library`，说明将合法下载的视频放入 `~/AnimeLibrary` 后扫描。

## 4. 后端边界

新增 `server/src/modules/catalog/`：

- `client.ts`：AniList GraphQL 请求、字段归一化、缓存。
- `editorial.ts`：少量按 AniList ID 的编辑推荐理由，不保存 AniList 数据副本。
- `routes.ts`：Fastify 路由与参数校验。

REST 接口：

- `GET /api/catalog/home` → 当前季、上一季、精选作品。
- `GET /api/catalog/search?q=关键字` → 最多 20 条非成人动画。
- `GET /api/catalog/anime/:id` → 单条详情；不存在返回 404，上游不可用返回 502。

统一 `CatalogAnime` 只暴露 UI 所需字段。外部链接过滤为 `STREAMING` 或 `INFO`，并要求 `https://`。

## 5. 错误与缓存

- 同一首页、搜索词或详情在 10 分钟内命中内存缓存，避免触发 AniList 限流。
- 上游 HTTP/GraphQL 错误统一为 `CatalogUpstreamError`；路由返回 `{ code: "CATALOG_UNAVAILABLE" }`。
- 搜索词 trim 后少于 2 个字符返回 400，不发送上游请求。
- 图片加载失败由 CSS 渐变背景兜底；缺评分、话数或 banner 时正常渲染。

## 6. 测试与完成标准

- server 单测：季度计算、HTML 清理、外部链接过滤、缓存命中、搜索校验、路由错误映射。
- web 单测：季度标签与状态文案等纯函数。
- 完整 `npm test` 全绿。
- 浏览器实测：发现页加载 2026 夏/春 → 搜索 `Frieren` → 打开详情 → 看到官方资源 → 进入本地媒体库。
- 320px 与桌面宽度均无横向溢出；播放器现有交互不回归。
